# 16 - Visual Benchmark

Live reference review completed on 2026-09-02 using browser-accessible page text and search results where a page had limited crawl output. The old Prof. Hemant Sheth website remains a content and SEO source only, not a visual reference.

## Principles Extracted

- Make the surgeon, title, scope and appointment route visible immediately.
- Use editorial hierarchy, restrained evidence and patient pathways instead of decorative trust widgets.
- Explain robotic surgery as surgeon-controlled technology, not autonomous superiority.
- Avoid repetitive card grids, fake counters, unsupported ratings and generic hospital stock imagery.
