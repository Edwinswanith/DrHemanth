# Audit schema — per-URL fields

Record every field for every discovered URL. Use "not available" (never a
guess) for anything requiring Search Console, GA4, or backlink export
access this environment doesn't have.

| Field | Notes |
|---|---|
| URL | Exact, as discovered |
| Discovery source | sitemap.xml / HTML sitemap / nav crawl / other |
| HTTP status | |
| Page type | home / bio / service / condition / location / legal / system (survey response, showcase, etc.) |
| Title tag | |
| Meta description | |
| H1 | |
| Canonical URL | |
| Indexability | indexable / noindex / blocked by robots |
| Word count (approx.) | |
| Internal links (count/notable targets) | |
| External links | |
| Images (count, notable) | |
| Documents (PDFs etc.) | |
| Structured data present | type(s), or none |
| Content-quality note | duplicate of / thinner than / factually mismatched vs. what |
| Medical-review classification | approved-reusable / reusable-after-editing / requires-clinical-rewrite / retire / requires-doctor-confirmation |
| Search traffic | value or "not available" |
| Backlinks | value or "not available" |
| Recommended destination (new URL or none) | |
| Migration decision | keep / improve / merge / redirect / retire / investigate |
| Verification status | verified / pending / n/a |
