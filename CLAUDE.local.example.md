# CLAUDE.local.example.md

Copy to `CLAUDE.local.md` (gitignored) for machine- or person-specific notes
that shouldn't be shared — local tooling quirks, personal shorthand, temporary
reminders. Do not put project rules here; those belong in `CLAUDE.md` or
`.claude/rules/`.

Example contents:

```
- Local Postgres for quick checks: postgresql://localhost:5432/keyholesurgeon_dev
- I prefer `npm run test -- --watch` while iterating on validation logic.
```
